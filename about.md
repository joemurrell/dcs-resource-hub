The **DCS Resource Hub** is a curated directory of tools, guides, and news for
[Digital Combat Simulator](https://www.digitalcombatsimulator.com/) — the kind
of links you want one click away instead of buried in a Discord scrollback or a
forum thread from three years ago.

### What's here

Each entry on the [resource index]({{ site.baseurl }}/) points to something
useful — a planning tool, a kneeboard reference, a tutorial series, a news
source — tagged by topic (Air-to-Air, Air-to-Ground, specific airframes, and
so on). Use the search box and tag filters to narrow things down, or browse by
category.

### Contributing

The list is intentionally curated rather than open-submission. Entries are
managed through a lightweight web editor at
[`/admin`]({{ site.baseurl }}/admin/) (GitHub sign-in required) — no local
setup needed. Adding or editing a link there commits the change back to the
repository, and the site rebuilds automatically.

If you'd rather propose a link without editing, open an issue or pull request
on [GitHub](https://github.com/joemurrell/dcs-resource-hub).

### Colophon

Built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages, with a
tactical-HUD theme. Content edits go through [Decap CMS](https://decapcms.org/),
authenticated by a small Cloudflare Worker OAuth proxy.
